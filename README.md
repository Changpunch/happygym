# 🏋️ Happy Gym

個人健身課表小工具：去健身房前快速排好今天要練什麼，訓練時逐組打勾，練完一鍵記錄回 Google 試算表，還能匯出當天的訓練圖卡。

> 網站內容已加密，需要密碼才能進入。

## 功能

- **選目標**：依部位（臀腿、手臂、肩、背、胸、核心…）或複合型訓練（主部位＋次部位），全部用下拉選單，可自行新增或隱藏部位
- **排課表**：分成熱身、重訓、有氧三個模組，不需要的可以跳過
  - 熱身：組數型（次數 × 組數）或時間型（時間、坡度、速度）
  - 重訓：從過去練過的動作中挑選，自動帶入上次的重量；器械或自由重量；kg / lb 切換並自動換算
  - 重量旁的 ⓘ 會顯示該動作的歷史最高重量，以及最近一次的日期、重量和組數
  - 有氧：依當天練的部位建議有氧時間（主練腿 15 分鐘、複合含腿 20–30 分鐘、沒練下肢 30 分鐘以上）
- **訓練中**：每做完一組就打勾，可以隨時加組、刪組、改重量和次數
- **結算**：統計訓練時間、組數、總訓練量，破紀錄會標 PR
  - 一鍵存回 Google 試算表（熱身／重訓／有氧三個分頁）
  - 匯出資訊圖卡，手機可直接分享或存到相簿

## 資料來源

訓練紀錄存在 Google 試算表，透過 Google Apps Script 網頁應用程式讀寫：

- 打開網頁時讀取歷史紀錄，手機會留一份快取，離線也能查看
- 結算後把完成的組數新增到試算表最下面，不會修改或刪除舊資料
- 每次存檔都會記在「網頁-存檔紀錄」分頁，同一次訓練不會重複寫入

## 技術

- 純 HTML / CSS / JavaScript 單一檔案，不需要建置工具或伺服器
- 內容以 AES-GCM 加密，密碼經 PBKDF2-SHA256（30 萬次）衍生金鑰後解密；登入後同一支手機會記住
- 圖卡用 Canvas 繪製輸出 PNG
- 後端為 Google Apps Script，搭配 Google 試算表

## 發佈

1. 把 `index.html` 上傳到 repo 根目錄
2. Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save
3. 等一兩分鐘後，用 `https://<帳號>.github.io/<repo 名稱>/` 開啟

> 必須用 https 開啟（GitHub Pages 預設就是），瀏覽器的加密功能才能運作。
