# 🏋️ Happy Gym

個人健身課表小工具：去健身房前快速排好今天要練什麼，訓練時逐組打勾，練完一鍵記錄回 Google 試算表，還能匯出當天的訓練圖卡。

> 網站內容已加密，需要密碼才能進入。

## 功能

### 👥 多帳號
- 每個人用自己的密碼登入，系統依密碼判斷是誰，不需要另外選人
- 頭貼、名字、課表、重量紀錄都各自分開；同一支手機登入一次就會記住
- 右上「⋯」→「切換帳號／登出」可以換人；排課流程中可按 🏠 回首頁

### 📊 首頁：訓練統計
- 登入後先看到這個帳號的訓練狀況，按「開始今天的訓練」才進入排課流程
- 本週訓練天數、本月訓練天數、距離上次訓練幾天
- 每週訓練天數（近 8 週）
- 訓練部位分布（近 30 天各部位練了幾天）
- 最近 5 次訓練
- 有還沒存到試算表的訓練時會提醒

### 1. 今天練什麼
- 預設為**複合型訓練**（主部位＋次部位，次部位可以加好幾個），也可以只選單一部位
- 部位全部用下拉選單，可以自行新增或隱藏
- 上方列出**最近練過的部位**作為參考：7 天內最近的 3 次；7 天內都沒練時，顯示上一次的日期和部位
- 依部位建議有氧時間：主練腿 15 分鐘、複合訓練含腿 20–30 分鐘、沒練下肢 30 分鐘以上

### 2. 排課表
- 分成熱身、重訓、有氧三個模組，不需要的可以跳過
- **照上次再做一次**：每個部位找「上一次練這個部位的那天」，照當天的動作、順序、每一組的重量和次數帶入
- 熱身：組數型（次數 × 組數）或時間型（時間、坡度、速度）
- 重訓：動作下拉選單只列當天選定部位的動作；一組一組列出，可以單獨調整；器械或自由重量；kg / lb 切換並自動換算
- 重量用**上下滑動的滾輪**選，並即時顯示換算成另一個單位的重量
- ⓘ 提示框：該動作的歷史最高重量，以及最近一次的日期、重量和組數
- 有氧：器材、時間、坡度／阻力、速度，以及目標心肺區間

### 3. 訓練中
- 每做完一組就打勾，上方顯示整體進度
- 可以隨時加組、刪組、改重量和次數
- 每個項目名稱旁有「📝 備註」，熱身、重訓、有氧都能寫，會一起存到試算表的備註欄；可一鍵帶入上次的備註

### 4. 結算
- 統計訓練時間、重訓動作數、組數、有氧時間，破個人紀錄會標 **PR**
- 一鍵存回 Google 試算表
- 匯出資訊圖卡，手機可以直接分享或存到相簿

## 資料存放

訓練紀錄存在 Google 試算表，透過 Google Apps Script 網頁應用程式讀寫：

- 每個帳號有自己的「熱身」「重訓」「有氧」分頁；新帳號的分頁會在第一次存檔時自動建立，欄位格式相同
- 打開網頁時讀取歷史紀錄，手機會留一份快取，網路不穩時也能使用
- 存檔只會把完成的組數新增到分頁最下面，不會修改或刪除舊資料
- 每次存檔都記在「網頁-存檔紀錄」分頁，同一次訓練不會重複寫入

## 技術

- 純 HTML / CSS / JavaScript 單一檔案，不需要建置工具或伺服器
- 內容以 AES-GCM 加密；每個帳號的密碼經 PBKDF2-SHA256（30 萬次）衍生金鑰後解開內容
- 圖卡用 Canvas 繪製並輸出 PNG
- 後端為 Google Apps Script，搭配 Google 試算表

## 發佈

1. 把 `index.html` 上傳到 repo 根目錄
2. Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save
3. 等一兩分鐘後，用 `https://<帳號>.github.io/<repo 名稱>/` 開啟

> 必須用 https 開啟（GitHub Pages 預設就是），瀏覽器的加密功能才能運作。
